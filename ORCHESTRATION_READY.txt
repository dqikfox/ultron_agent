HOW IT WORKS

  Amazon Q (Me)          →  Provides tasks, requirements, context
  You (Orchestrator)     →  Delegates to local models via Continue
  Local Models           →  Execute tasks following workflows
  You (Verifier)         →  Check results, iterate if needed

QUICK START (3 STEPS)

  1. Open VS Code
  2. Press Ctrl+L
  3. Type: @prompt orchestration_workflow [your task]

TRY THE DEMO

  Ctrl+L → Type:

  "hello" commands and responds with friendly greeting. Use
  ultron_logger and follow ToolInterface pattern.

  - Create tools/hello_tool.py
  - Implement match() and execute()
  - Add logging and error handling
