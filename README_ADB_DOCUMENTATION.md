## 🚀 Getting Started in 5 Minutes

### Step 1: Install ADB (2 min)
```powershell
choco install adb
# or download from developer.android.com/tools/adb
```

### Step 2: Enable Device Debugging (2 min)
- Device Settings → About Phone → Build Number (tap 7x)
- Settings → Developer Options → USB Debugging (ON)
- Connect USB cable

### Step 3: Start ULTRON (1 min)
```powershell
.\run.bat
```

### Step 4: Access ADB Manager
- Open browser: `http://localhost:8080/adb`
- See your device in the list
- Start using!
