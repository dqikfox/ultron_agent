### Common Issues
| Issue | Solution | Doc |
|-------|----------|-----|
| Backend won't start | Check port/dependencies | `TROUBLESHOOTING_DEPLOYMENT.md` |
| Device not detected | USB debugging enabled? | `ADB_MANAGER_README.md` |
