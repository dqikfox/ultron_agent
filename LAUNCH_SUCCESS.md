## 🔧 Troubleshooting

### Server Not Responding?
```bash
# Check if server is running
curl http://localhost:8082/api/models/avatars

# Restart server
# Close the server window and run:
python avatar_game_server.py
```

### Voice Not Working?
- Check browser permissions (allow microphone)
- Click "🎤 Voice" to enable
- Speak clearly and wait for recognition

### ULTRON Integration Failed?
- Start main ULTRON: `python main.py`
- Check port 8001 is available
- Click "🔗 Integrate" again

### Database Issues?
- Check `avatar_game.db` file exists
- Restart server to reinitialize
- Check logs for errors
