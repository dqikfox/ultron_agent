If diagnostic & repair don't solve it, try these:


OPTION 1: Reset PowerShell Execution Policy
─────────────────────────────────────────

Run PowerShell AS ADMIN and paste:

  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope LocalMachine -Force


OPTION 2: Fix Batch File Association
──────────────────────────────────────

Run CMD AS ADMIN and paste:

  assoc .bat=batfile
  assoc .cmd=cmdfile
  ftype batfile=%COMSPEC% /c "%%1"
  ftype cmdfile=%COMSPEC% /c "%%1"


OPTION 3: Remove DisableCMD Registry Key
─────────────────────────────────────────

Run CMD AS ADMIN and paste:

  reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System" /v DisableCMD /f


OPTION 4: Check AppLocker Policy
────────────────────────────────

Run PowerShell AS ADMIN:

  Get-AppLockerPolicy -Effective


OPTION 5: Full System Scan
──────────────────────────

Run CMD AS ADMIN:

  sfc /scannow

  Then restart Windows.


OPTION 6: Reset Graphics Driver
──────────────────────────────

Device Manager → Display Adapters → Right-click GPU → Update Driver
