EMERGENCY QUICK FIX GUIDE
================================================================================

"GUI won't load"
→ Check: curl http://localhost:8080
→ Check: Is Ollama running? curl http://localhost:11434/api/tags
→ Fix: Restart Ollama, then restart Web GUI

"AI doesn't respond"
→ Check: curl http://localhost:11434/api/tags
→ Fix: Pull model: ollama pull llava:7b
→ Restart: Stop-Process -Name "ollama" -Force

"Port already in use"
→ Find: Get-NetTCPConnection -LocalPort [port]
→ Kill: Stop-Process -Id [PID] -Force
→ Check: What was using it before stopping

"System won't start"
→ Check: Get-Content logs/agent_core.log -Tail 50
→ Check: Run.bat output
→ Fix: Kill existing processes, try again

"My change broke something"
→ Option 1: git checkout HEAD -- [file]
→ Option 2: Copy from .backup file
→ Option 3: git revert HEAD
→ Restart: Services after rollback
