## 🚀 Quick Import (5 Minutes)

### 1. Open Unity Project
```
1. Open Unity Hub
2. Create New Project > 2D (Core)
3. Name: "ULTRON_Platformer"
4. Create Project
```

### 2. Import Scripts
```
1. In Unity: Assets > Create > Folder > "Scripts"
2. Copy ALL files from: UnityGame/Assets/Scripts/
3. Paste into: YourProject/Assets/Scripts/
4. Wait for compilation (check bottom-right)
```

### 3. Import ONNX Models
```
1. In Unity: Assets > Create > Folder > "Models"
2. Copy: UnityGame/Assets/Models/*.onnx
3. Paste into: YourProject/Assets/Models/
4. Unity will auto-import as ModelAssets
```

### 4. Create Player (2 minutes)
```
1. Hierarchy > Create > 2D Object > Sprite > Square
2. Rename to "Player"
3. Add Component > Rigidbody 2D
4. Add Component > Box Collider 2D
5. Add Component > PlayerController (script)
6. Create Empty Child: "GroundCheck" (position at feet)
7. In Inspector: Assign GroundCheck to script
8. Set Ground Layer Mask to "Default"
```

### 5. Create Enemy (2 minutes)
```
1. Hierarchy > Create > 2D Object > Sprite > Circle
2. Rename to "Enemy"
3. Change color to red (Sprite Renderer)
4. Add Component > AIEnemy (script)
5. Assign Player to "Player" field
6. Assign EnemyAI.onnx to "Model Asset" field
7. Set Patrol Points (click + to add positions)
```

### 6. Setup Camera
```
1. Select Main Camera
2. Add Component > CameraFollow (script)
3. Assign Player to "Target" field
4. Set Offset: (0, 2, -10)
```

### 7. Create Ground
```
1. Hierarchy > Create > 2D Object > Sprite > Square
2. Rename to "Ground"
3. Scale: (20, 1, 1)
4. Position: (0, -3, 0)
5. Add Component > Box Collider 2D
```

### 8. Test Play
```
Press Play button (top center)
- WASD/Arrows to move
- Space to jump
- Enemy should patrol/chase
```

## 🎮 Controls

- **Move**: WASD or Arrow Keys
- **Jump**: Space
- **Exit Play Mode**: Press Play button again

## 🔧 Troubleshooting

**"Script missing"**: Reimport scripts, check for compile errors  
**"Model Asset null"**: Drag .onnx file from Models folder to script field  
**Player falls through ground**: Add Box Collider 2D to ground  
**Enemy doesn't move**: Set patrol points in inspector
