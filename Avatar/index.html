Procedural Avatar

  • 4 Emotional States (Happy, Neutral, Focused, Alert)

Trooper Model

Pre-exported OBJ/MTL model viewer. Loads the TOON TROOPER character directly from existing files.

  • OBJ format with MTL materials
  • Auto-rotation control
  • Wireframe toggle
  • 3 Lighting modes (Green, Blue, Red)
  • Orbit camera controls
  • ULTRON-themed lighting

ULTRON Blender Model

High-quality Blender model viewer. Requires exporting the .blend file to GLB format first.

  • Full Blender model support
  • Animation playback (if exported)
  • Advanced materials and textures
  • Model statistics display
  • Adjustable rotation speed
  • Dynamic zoom controls

🎯 Quick Start Guide

Option 1: Use Procedural Avatar - Click "Procedural Avatar" card above. No setup needed!

Option 2: Use Trooper Model - Click "Trooper Model" card above. Loads instantly!

Option 3: Export Blender Model

  1. Open Blender and load ultron+xps.blend
  2. Switch to Scripting tab
  3. Open and run export_to_web.py
  4. Wait for "Model exported successfully" message
  5. Launch "ULTRON Blender Model" viewer above
