═══════════════════════════════════════════════════════════════════════════════
USAGE GUIDE
═══════════════════════════════════════════════════════════════════════════════

Building Docker Image:

Linux/macOS:
$ ./build.sh                          # Default build
$ ./build.sh --no-cache               # Rebuild without cache
$ ./build.sh --push                   # Build and push to registry
$ ./build.sh --version 3.0.1          # Custom version

Windows:
$ build.bat                           # Default build
$ build.bat --no-cache                # Rebuild without cache
$ build.bat --push                    # Build and push to registry

Deploying Services:

Linux/macOS:
$ ./deploy.sh development deploy      # Deploy development
$ ./deploy.sh production deploy       # Deploy production
$ ./deploy.sh development stop        # Stop development
$ ./deploy.sh development restart     # Restart development
$ ./deploy.sh development logs        # View development logs
$ ./deploy.sh development status      # Show status
$ ./deploy.sh development backup      # Create backup

Windows:
$ deploy.bat development deploy       # Deploy development
$ deploy.bat production deploy        # Deploy production
$ deploy.bat development stop         # Stop development

Docker Compose Direct:
$ docker-compose up -d                # Start all services
$ docker-compose ps                   # Show service status
$ docker-compose logs -f              # Follow logs
$ docker-compose down                 # Stop all services
$ docker-compose restart              # Restart all services

TROUBLESHOOTING DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════════

Issue: Build fails with "Dockerfile not found"
→ Ensure you're in the project root directory
→ Verify Dockerfile exists: ls -la Dockerfile

Issue: Docker daemon not responding
→ Start Docker service: sudo systemctl start docker (Linux)
→ Or start Docker Desktop (macOS/Windows)
→ Verify: docker ps

Issue: Port already in use
→ Check running containers: docker ps
→ Stop conflicting container: docker stop <container_id>
→ Or use different ports in docker-compose.yml

Issue: Services fail to start
→ Check logs: docker-compose logs
→ Verify dependencies: docker-compose ps
→ Check health: curl http://localhost:5000/health

Issue: Health check failing
→ Wait longer (40s startup grace)
→ Check service is actually running
→ Verify network connectivity
